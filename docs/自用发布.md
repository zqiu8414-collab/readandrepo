# 自用分支发布

版本号只在 `manifest.json` 中修改，更新 `CHANGELOG.md` 后运行：

```sh
node dev/prepare-release.mjs
node dev/prepare-release.mjs --check
```

脚本会统一入口、样式、全部自有运行模块的资源版本，并生成当前代码版本常量。检查模式只读；发现漏改的导入或不存在的相对模块时退出失败。宿主绝对模块与 vendored 库保持原地址。

发布须包含脚本生成的所有运行模块，不能只上传入口或 manifest。随仓库附带的验证模块也统一导入版本，避免自测另建一份存储实例。`--list` 输出文件清单供发布工具使用；清单不包含开发数据和历史交接文件。README 仅保留“自用插件”。

设置显示当前实际运行的脚本版本。检查更新发现安装文件比当前页面新时，显示刷新入口；刷新后新资源版本生效。
